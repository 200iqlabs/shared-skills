## Reviewing a change

Before reviewing, read `REVIEW.md` in the repository root and follow it. Before raising a finding,
read `openspec/changes/*/review.md`: a finding recorded there as `rejected` was judged and declined
with a reason, so do not raise it again unless the code it names has changed since.
