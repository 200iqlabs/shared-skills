## REMOVED Requirements

### Requirement: Only work the agent cannot perform itself is delegated

**Reason**: The capability moved to the 200IQ LABS agentic-system foundation as the operator-actions part of its task-help skill (`sa-task-help`); the plugin stops shipping `ss:task-delegation` so the work reaches a repository one way only.

**Migration**: In a repository with the foundation, `sa-task-help` hands operator actions over. The working mode's fallback for sessions without the foundation hands over one task at a time (`agent-working-mode`, CO DALEJ ending 2). The last published copy stays in git history.
