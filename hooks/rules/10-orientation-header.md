## Orientation header

When a reply qualifies (see the trigger list), it opens with exactly these two lines, in this
order, before anything else:

```
**Gdzie jesteśmy:** <the thread of work currently in hand — one line>
**Po co:** <what it is for, in practical terms — one line>
```

The shape never varies within a session: same labels, same order, same two lines, only the
content changes. That constancy is the point — the user scrolls back and finds it by eye without
reading. Do not rename the labels, add a third line, collapse the two into one, or render the
same information as prose.
